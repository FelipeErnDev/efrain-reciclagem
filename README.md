# Reciclagem Efrain

Site institucional da Reciclagem Efrain (Lucas Efrain Branco ME) — compra e venda de materiais reciclados em Rio do Sul / SC.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- Framer Motion

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Páginas

- `/` — Home
- `/sobre-nos` — Sobre nós
- `/materiais` — Materiais
- `/sucatas` — Sucatas
- `/contato` — Contato

## Configuração

Edite `src/lib/constants.ts` para telefone, WhatsApp, e-mail, Instagram e demais dados.
